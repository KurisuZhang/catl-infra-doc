### 一、系统整体架构设计

我们将构建以下三个核心组件：



1. **教师网络（Teacher）**：含2个卷积层 + 2个全连接层的深度网络（约 **120万参数**）。

2. **学生网络（Student）**：仅含1个卷积层 + 1个全连接层的轻量网络（约 **4万参数**）。

3) **蒸馏训练器（Distiller）**：负责计算 **软标签损失（KL散度）** + **硬标签损失（交叉熵）**。

**实验组设置**：



* **对照组**：学生网络从零开始训练（只用硬标签）。

* **实验组**：学生网络在教师网络的“软标签”指导下训练（蒸馏）。

### 二、环境准备与数据加载

import torch.optim as optim

# 固定随机种子，保证实验可复现

# 数据预处理：MNIST标准归一化

    transforms.ToTensor(),
    transforms.Normalize((0.1307,), (0.3081,))
])

# 加载MNIST数据集
train_dataset = datasets.MNIST(root='./data', train=True, download=True, transform=transform)

# 为了加快演示速度，训练集只取前 20000 张（通常会用全部60000张）

test_loader = DataLoader(test_dataset, batch_size=1000, shuffle=False, num_workers=2)

### 三、定义教师网络与学生网络

这里的关键是**结构解耦**——教师和学生的结构完全独立，学生不需要复制教师的结构，只需模仿其输出。



```python
# ---------- 教师模型（大而强） ----------
class TeacherNet(nn.Module):
    def __init__(self):
        super(TeacherNet, self).__init__()
        self.conv1 = nn.Conv2d(1, 32, kernel_size=3, padding=1)   # 输出: 32x28x28
        self.conv2 = nn.Conv2d(32, 64, kernel_size=3, padding=1)  # 输出: 64x28x28
        self.pool = nn.MaxPool2d(2, 2)  # 每次池化尺寸减半
        # 经过两次池化: 28 -> 14 -> 7
        self.fc1 = nn.Linear(64 * 7 * 7, 128)
        self.fc2 = nn.Linear(128, 10)
        self.dropout = nn.Dropout(0.2)

    def forward(self, x):
        x = self.pool(F.relu(self.conv1(x)))
        x = self.pool(F.relu(self.conv2(x)))
        x = x.view(-1, 64 * 7 * 7)
        x = F.relu(self.fc1(x))
        x = self.dropout(x)
        return self.fc2(x)  # 注意：这里输出logits，不经过Softmax

# ---------- 学生模型（小而精） ----------
class StudentNet(nn.Module):
    def __init__(self):
        super(StudentNet, self).__init__()
        self.conv1 = nn.Conv2d(1, 16, kernel_size=3, padding=1)   # 输出: 16x28x28
        self.pool = nn.MaxPool2d(2, 2)  # 28 -> 14
        self.fc1 = nn.Linear(16 * 14 * 14, 32)
        self.fc2 = nn.Linear(32, 10)

    def forward(self, x):
        x = self.pool(F.relu(self.conv1(x)))
        x = x.view(-1, 16 * 14 * 14)
        x = F.relu(self.fc1(x))
        return self.fc2(x)  # 输出logits
```

### 五、训练教师网络（先当“名师”）

教师必须在原始任务上达到接近SOTA的精度，否则“上梁不正下梁歪”。



```python
def train_teacher(teacher, epochs=5, lr=0.001):
    print("\n--- 开始训练教师网络 ---")
    optimizer = optim.Adam(teacher.parameters(), lr=lr)
    criterion = nn.CrossEntropyLoss()
    
    for epoch in range(epochs):
        teacher.train()
        total_loss = 0
        for batch_idx, (data, target) in enumerate(train_loader):
            data, target = data.to(device), target.to(device)
            optimizer.zero_grad()
            output = teacher(data)
            loss = criterion(output, target)
            loss.backward()
            optimizer.step()
            total_loss += loss.item()
        
        # 测试集评估
        teacher.eval()
        correct = 0
        with torch.no_grad():
            for data, target in test_loader:
                data, target = data.to(device), target.to(device)
                output = teacher(data)
                pred = output.argmax(dim=1)
                correct += (pred == target).sum().item()
        acc = 100. * correct / len(test_dataset)
        print(f"Epoch {epoch+1}: 训练Loss: {total_loss/len(train_loader):.4f} | 测试准确率: {acc:.2f}%")
    
    return teacher

# 执行训练（如果已有预训练模型，可跳过此步）
teacher = train_teacher(teacher, epochs=5)
```



**预期结果**：教师网络 5 轮后测试准确率可达 **99.1% - 99.3%**。

### 六、核心：蒸馏损失函数（代码即公式）

这是我们第6课理论的具体落地。温度 `T` 让教师输出的概率分布变“软”，凸显暗知识。



```python
def distillation_loss(student_logits, teacher_logits, target_labels, temperature=4.0, alpha=0.7):
    """
    参数:
        student_logits: 学生网络的原始输出（未经Softmax）
        teacher_logits: 教师网络的原始输出（未经Softmax）
        target_labels: 真实标签（硬标签）
        temperature: 温度系数，通常设为 3~8
        alpha: 软标签损失的权重，0.7表示70%学老师，30%学真实答案
    """
    # ---- 1. 软标签损失（KL散度） ----
    # 将logits除以温度后做LogSoftmax
    student_soft = F.log_softmax(student_logits / temperature, dim=1)
    teacher_soft = F.softmax(teacher_logits / temperature, dim=1)
    # KL散度计算，注意 reduction='batchmean'
    kl_loss = F.kl_div(student_soft, teacher_soft, reduction='batchmean')
    # 乘以 T^2 是为了补偿温度导致的梯度缩小（这是Hinton原论文的关键技巧）
    soft_loss = kl_loss * (temperature ** 2)
    
    # ---- 2. 硬标签损失（交叉熵） ----
    hard_loss = F.cross_entropy(student_logits, target_labels)
    
    # ---- 3. 加权求和 ----
    return alpha * soft_loss + (1 - alpha) * hard_loss
```

### 七、蒸馏训练主循环（“学生上课”）

在蒸馏训练中，教师网络**冻结参数**，只做前向推理。学生网络正常反向传播。



```python
def train_student_with_distillation(teacher, student, epochs=10, lr=0.001, temp=4.0, alpha=0.7):
    print("\n--- 开始知识蒸馏训练 (教师指导学生) ---")
    optimizer = optim.Adam(student.parameters(), lr=lr)
    
    # 将教师设置为评估模式，冻结BatchNorm和Dropout
    teacher.eval()
    
    for epoch in range(epochs):
        student.train()
        total_loss = 0
        for batch_idx, (data, target) in enumerate(train_loader):
            data, target = data.to(device), target.to(device)
            
            optimizer.zero_grad()
            
            # 1. 教师前向传播（不计算梯度，节省显存）
            with torch.no_grad():
                teacher_logits = teacher(data)
            
            # 2. 学生前向传播
            student_logits = student(data)
            
            # 3. 计算蒸馏损失
            loss = distillation_loss(student_logits, teacher_logits, target, 
                                     temperature=temp, alpha=alpha)
            
            loss.backward()
            optimizer.step()
            total_loss += loss.item()
        
        # 验证
        student.eval()
        correct = 0
        with torch.no_grad():
            for data, target in test_loader:
                data, target = data.to(device), target.to(device)
                output = student(data)
                pred = output.argmax(dim=1)
                correct += (pred == target).sum().item()
        acc = 100. * correct / len(test_dataset)
        print(f"蒸馏 Epoch {epoch+1}: 训练Loss: {total_loss/len(train_loader):.4f} | 测试准确率: {acc:.2f}%")
    
    return student
```

### 八、对照组：学生“裸奔”训练（无蒸馏）

### 十一、如何把这份代码“平移”到大模型（LLM）场景？

MNIST代码虽然简单，但其**核心逻辑完全适用于LLM**。以下是迁移映射表：



| MNIST代码组件             | LLM大模型蒸馏中的对应物                                        |
| --------------------- | ---------------------------------------------------- |
| `TeacherNet` (CNN)    | **LLaMA-3-70B** 或 **GPT-4** (通过API)                  |
| `StudentNet` (浅层CNN)  | **Qwen-1.5B**、**Phi-3-mini** 或 **MobileLLM**         |
| `data` (28x28像素)      | 输入 **Prompt** + **Response** (文本Token序列)             |
| 硬标签 `target` (数字0-9)  | 下一个Token的 **One-hot** 标签                             |
| 软标签 `teacher_logits`  | 教师模型输出的 **Token概率分布** (词典大小 \~ 50k)                  |
| 交叉熵 `F.cross_entropy` | 标准 **因果语言建模** (CLM) 损失                               |
| KL散度 `F.kl_div`       | 在**序列维度**上求平均的KL散度 (通常使用 `KLDivLoss` 配合 `batchmean`) |





**LLM蒸馏的关键修改点**：



1. **损失计算维度**：LLM输出是 `[Batch, Seq_len, Vocab]`，需要在 `Seq_len` 维度上计算KL散度后取平均。

2. **教师推理成本**：LLM教师（如70B）前向传播极慢。实践中，我们会**离线生成软标签**（一次性跑完整个数据集），将 `teacher_logits` 保存到磁盘，训练时直接加载，避免重复推理。

3) **序列级别的温度**：在生成任务中，温度通常设为 **2\~5**，能显著提升小模型生成文本的多样性。

***



### 十二、这行代码帮你避开一个“巨坑”

在蒸馏训练中，**千万不要**在学生训练时对教师调用 `teacher.train()`，务必加上 `with torch.no_grad():`，否则：



* 教师的Dropout层会随机丢弃神经元，导致软标签抖动。

* BatchNorm会使用当前Batch的统计量，而非全局统计量，使软标签失真。

* 反向传播会试图更新教师参数（虽然你大概率没写优化器），浪费显存和算力。

```python
# ✅ 正确姿势
with torch.no_grad():
    teacher_logits = teacher(data)

# ❌ 错误姿势（千万注意）
# teacher_logits = teacher(data)  # 少了 no_grad，且教师可能处于 train() 模式
```
